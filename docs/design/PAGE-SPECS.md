# Page Specifications

- **Home:** integrated food-led hero with stable Menu/Directions CTAs, compact action strip, commercial Featured Meals, physical-board menu preview, paired Story/Visit band, and mobile food prominence in the first viewport.
- **Menu:** indexable categories and photographed-board prices with source/date and call-to-confirm disclosure.
- **Our Story:** strongest cinematic artifact progression; storefront → heritage letter board → current burger board → current Mediterranean board. Copy remains subordinate to large artifacts.
- **Contact:** verified NAP, phone, directions, and explicit hours uncertainty.
- **Gallery:** authentic customer-contributed storefront, food, and menu-board images.
- **404:** branded recovery with direct Menu action.

Shared header, footer, and mobile conversion bar keep navigation consistent.

Secondary-route mastheads are compact by design so the route's useful content begins in or immediately after the first viewport.
