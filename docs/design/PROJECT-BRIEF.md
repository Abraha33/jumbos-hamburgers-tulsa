# Jumbo's Website — Project Goal

## Primary objective
Generate more customers for Jumbo's Hamburgers by helping visitors view the menu, want the food, get directions, call, and visit.

## Priority
Home → Menu → Our Story → Contact/Location → Gallery → 404.

## Differentiator
A conversion-first dimensional experience inspired by Jumbo's real black/yellow menu boards, physical restaurant, checker paper, trays, and heritage letter boards. The site is a new visual version; the previous layout and design language are not a baseline.

## Experience principle
ATTENTION → APPETITE → INFORMATION → TRUST → ACTION
